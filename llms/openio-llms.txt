# OpenIO

> OpenIO SDS is an open-source, software-defined object storage platform for building hyper-scalable, high-performance storage infrastructures. It exposes data through an Amazon S3-compatible gateway and an OpenStack Swift-compatible gateway, with native Python, C and Java client libraries and an `openio` command-line interface. OpenIO was acquired by OVHcloud in 2020; the SDS project remains publicly documented.

## APIs
- [S3-Compatible Object Storage API](https://docs.openio.io/latest/source/arch-design/s3_compliancy.html): Amazon S3-compatible gateway (Signature v2/v4, versioning, lifecycle, CORS, tagging, ACLs, multipart).
- [OpenStack Swift API](https://docs.openio.io/latest/source/user-guide/swiftapi.html): Swift-compatible gateway.
- [Native oio-sds service APIs](https://docs.openio.io/latest/): RAWX, Conscience, Directory, Container, Content, Account, Reverse-Directory REST services.
